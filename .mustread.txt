INTERFACE DEFINITIONS
================================================================================

TransactionEntry Interface:
  - timestamp: string (Format: "Oct 24, HH:MM:SS")
  - type: 'scan-pay' | 'transfer' | 'withdrawal' | 'funding' | 'settlement'
  - sourceChannel: string (e.g., "MTN Mobile Money", "F2P Transfer")
  - debit: number | null (Money going out)
  - credit: number | null (Money coming in)
  - systemBalance: number (Current system balance)
  - status: 'cleared' | 'pending' | 'failed'
  - icon: string (Font Awesome icon class)

================================================================================
HELPER METHODS REFERENCE
================================================================================

formatAmount(amount: number): string
  • Formats currency using toLocaleString('fr-CM')
  • Input: 1248500000 → Output: "1 248 500 000"
  • Handles null/undefined gracefully

getStatusClass(status: string): string
  • Returns CSS classes for status badges
  • 'cleared' → emerald styling
  • 'pending' → amber styling
  • 'failed' → red styling

getTypeIcon(type: string): string
  • Returns Font Awesome icon class for transaction type
  • scan-pay → fa-qrcode
  • transfer → fa-exchange
  • withdrawal → fa-building
  • funding → fa-arrow-down
  • settlement → fa-scale-balanced

getTypeLabel(type: string): string
  • Returns readable label for transaction type
  • scan-pay → "Scan & Pay"
  • transfer → "Transfer"
  • etc.

getTypeColorClass(type: string): string [NEW]
  • Returns color-coded CSS classes for transaction type badges
  • scan-pay → blue colors
  • transfer → purple colors
  • withdrawal → red colors
  • funding → emerald colors
  • settlement → amber colors

getSourceIcon(type: string): string [NEW]
  • Returns appropriate icon for transaction source channel
  • Helps distinguish where transaction originated

filteredTransactions (getter)
  • Filters transactions based on searchTerm and selectedFilter
  • Supports search by sourceChannel and timestamp
  • Supports filter by transaction type
